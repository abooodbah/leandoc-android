# Content rating answers (IARC questionnaire)

Play Console > App content > Content rating. Category: "All other app
types" (reference, utility). LeanDoc is a read-only viewer for files that
are already on the phone. It has no accounts, no chat, no sharing between
users, no ads and no purchases.

| Question | Answer |
| --- | --- |
| Violence, blood or gore | No |
| Sexual content or nudity | No |
| Offensive language or crude humor | No |
| Controlled substances (drugs, alcohol, tobacco) | No |
| Gambling, real or simulated | No |
| Fear or horror content | No |
| Can users interact or exchange content with each other? | No |
| Does the app share the user's location with other users? | No |
| Does the app allow purchases of digital goods? | No |
| Is the app a web browser or search engine? | No. Links in a document open in the user's own browser after a tap. |
| Does the app contain user-generated content shared with others? | No. It shows only files the user opens. |

Expected result: the lowest rating in each system (for example IARC 3+,
PEGI 3, ESRB Everyone). Any question not listed here is also "No".
